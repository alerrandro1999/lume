# FFmpeg no Estúdio de Transcrição

O Lume executa o FFmpeg como um programa separado para extrair o áudio de arquivos MP4 e M4A. O binário FFmpeg e as DLLs de terceiros na pasta `runtime/ffmpeg` são provenientes do pacote Windows x64 LGPL compartilhado do projeto FFmpeg-Builds. Os arquivos incluídos são usados sem modificações.

- Versão `n8.1.3-35-gf1acb0a266`, build `autobuild-2026-11-16-15-29`.
- [Pacote original e checksums](https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases/tag/autobuild-2026-11-16-15-29).
- [Código fonte do FFmpeg nessa revisão](https://github.com/FFmpeg/FFmpeg/tree/f1acb0a266).
- [Configuração e receitas usadas pelo projeto de builds](https://github.com/FFmpeg-Builds/FFmpeg-Builds).

O texto da licença fornecido pelo pacote original está em `runtime/ffmpeg/LICENSE.txt`. O comando `runtime/ffmpeg/ffmpeg.exe -buildconf` exibe as opções da versão instalada.
